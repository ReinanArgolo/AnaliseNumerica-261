\section{Linguagem Escolhida e Justificativas}
Foi utilizada a linguagem Python por sua sintaxe simples, boa legibilidade e facilidade para expressar diretamente as fórmulas dos métodos numéricos. As implementações foram feitas sem \texttt{numpy}, \texttt{pandas} ou \texttt{scipy}, usando apenas recursos básicos da linguagem, o módulo \texttt{math}, o módulo \texttt{csv} e a biblioteca \texttt{matplotlib} para geração dos gráficos.

A restrição ao uso de bibliotecas prontas teve importância pedagógica. Ao implementar manualmente os métodos de integração, a resolução de sistemas de equações diferenciais e o algoritmo de Thomas para sistemas tridiagonais, tornou-se possível acompanhar cada etapa do processo numérico: cálculo das inclinações, avanço de passo, acúmulo de erro, montagem de sistemas lineares e validação das aproximações. Assim, o código não atua como uma caixa-preta, mas como uma representação computacional direta dos procedimentos estudados na disciplina.
